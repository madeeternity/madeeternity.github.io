# madeeternity — BIO website

Личный сайт-визитка на чистом HTML, CSS и JavaScript.

## Запуск локально
Откройте `index.html` в браузере. Для разработки можно использовать расширение Live Server.

## Публикация на GitHub Pages
1. Создайте на GitHub публичный репозиторий с именем `ВАШ_ЛОГИН.github.io`.
2. Загрузите в корень репозитория `index.html`, `style.css`, `script.js`, папку `assets` и этот README.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите Save.
6. После публикации сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io`.

GitHub Pages автоматически обновляет сайт после каждого push/commit в выбранную ветку. Отдельный сервер или постоянный процесс запуска не нужен: это статический сайт.

## Настройка
- Замените `madeeternity` и ссылки на свои в `index.html`.
- Измените описания проектов в `script.js`.
- Навыки и проценты находятся в `index.html` в секции `Мои навыки`.
- Изображения проектов лежат в `assets/`.
- Переключатель темы сохраняет выбор в браузере.
