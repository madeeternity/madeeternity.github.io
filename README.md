# MadeEternity — BIO

Обновлённая версия персонального сайта в эстетике macOS Liquid Glass.

## Файлы
- `index.html` — структура сайта
- `style.css` — оформление и адаптивная версия
- `script.js` — автономный ambient shader, модальные окна проектов и интерактивный терминал
- `assets/` — изображения проектов

## Публикация на GitHub Pages
Загрузите содержимое архива в корень репозитория `madeeternity.github.io`, сохранив папку `assets`.
В Settings → Pages выберите `Deploy from a branch`, ветку `main`, папку `/ (root)`.

Терминал поддерживает команды: `help`, `about`, `skills`, `projects`, `contact`, `clear`, `date`.
