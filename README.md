# MadeEternity — BIO

Обновлённый сайт в эстетике macOS Liquid Glass.

- Анимации появления секций и проектов при прокрутке.
- Убран аватароподобный элемент с буквой M.
- Абстрактная стеклянная композиция с мягким движением вместо аватара.
- Проекты оформлены крупными горизонтальными блоками с видимыми описаниями и характеристиками.
- Сохранены интерактивный Arch Linux terminal и автономный ambient shader.

Загрузите содержимое архива в корень `madeeternity.github.io`, сохранив папку `assets`.
